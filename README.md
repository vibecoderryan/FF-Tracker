# EINSATZ.LOG 1.7.2 – Entwicklungsversion

Das Paket enthält alle für GitHub Pages und Netlify benötigten Dateien direkt im Hauptverzeichnis. `index.html` gehört ins Repository-Hauptverzeichnis.

## Vor dem Update

1. Aus der bisher funktionierenden App ein aktuelles JSON-Backup erstellen und sicher in der iPhone-Dateien-App ablegen.
2. Den bestehenden Webauftritt und die bisherigen Website-Daten nicht löschen.
3. Alle Dateien dieses Pakets in das bestehende Repository-Hauptverzeichnis hochladen; gleichnamige Dateien überschreiben.
4. Nach dem Deployment den Start, alte Einträge, Kalender, Einstellungen, Export und PDF-Erstellung prüfen.
5. Erst nach erfolgreicher Kontrolle das neue Paket dauerhaft verwenden.

## Umfang und Einschränkungen

Enthalten sind erste Funktionen von 1.7.2: gruppierte Einstellungen, Kompaktmodus, Anzeigeoptionen für Kalenderwochen und Symbole, Startseitenprofile, Menüsortierung, Standard-Akzentfarbe, manuelle Beitragsgenerator-Vorlagen, Textbausteine, Hashtags, Veröffentlichungszähler, favorisierte Stichwörter und Fahrzeuge, Jahresvergütungsübersicht mit Auszahlungsdatum sowie Backup-Lesetest.

**Leitstelle Lausitz:** Es gibt eine separate Informationsseite mit dem geplanten Filter für Miersdorf/Zeuthen. Noch keine Live-Datenanbindung: Die Datenquelle/API für die letzten drei Meldungen und die Nutzungsbedingungen müssen zuerst zuverlässig geprüft werden. Es werden keine Einsatzdaten erfunden oder automatisch übernommen.

Dies ist eine **Entwicklungs-/Testversion**, kein vollständig abgeschlossenes 1.7.2. Insbesondere die erweiterten Einsatzrekorde und zusätzliche Verbesserungen der Tagesübersicht sind noch offen. Browser- und iPhone-Tests sind noch ausstehend. Die IndexedDB-Version bleibt 11, es werden keine bestehenden Datenspeicher gelöscht.
